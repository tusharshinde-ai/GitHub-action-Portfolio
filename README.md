# Tushar Shinde — Cloud & DevOps Portfolio

A responsive, dark-theme static portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local server:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000`.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `tushar-cloud-devops-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub Pages will publish the site and show its URL in the Pages settings.

## Before publishing
- Add your LinkedIn profile URL in the contact section (currently shown as a reminder).
- Confirm that the displayed phone number and email address are the contact details you want public.
- The resume is included in `assets/` for the download link.
- Project descriptions are presented as project experience, not as additional employment history.
